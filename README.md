## Телефон ва компьютерга ўрнатиш
- **Android (Chrome):** сайтни очинг → «📲 Ўрнатиш» тугмаси ёки менюдан «Установить приложение». Иконка экранга тушади, интернетсиз ҳам очилади.
- **iPhone (Safari):** «Поделиться» → «На экран Домой».
- **Компьютер (Chrome/Edge):** манзил қаторидаги ⊕ «Установить» белгиси.
- **APK файл керак бўлса:** https://www.pwabuilder.com га сайт манзилини қўйинг → Android → APK юклаб олинади.

## Телефон ↔ компьютер синхронлаш
«Созламалар → Синхронлаш» да бепул Firebase уланади (йўриқнома шу ерда ёзилган). Иккала қурилмада бир хил email билан кирилса, маълумот ўзи бир хил бўлади.
